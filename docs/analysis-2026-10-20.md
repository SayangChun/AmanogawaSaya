## 2. 做得好的部分（保留）

- **主/渲染进程边界干净**：preload 只暴露最小 API 集，contextIsolation 开启、nodeIntegration 关闭。
- **帧动画防竞态细致**：`showFrame` 的 swapToken 校验、双图层硬切（避免粉色描边叠加闪粉）、`preloadAll` 只在进程生命周期跑一次。
- **窗口锚点系统**：setMode 保持身体中心-X 与脚底-Y 不动，dock 左/右自适应（chooseDockPlacement 按剩余空间），clampToWorkArea 选最大重叠显示器 —— 多显示器场景处理正确。
- **行为编排**：链内不回 idle、holdMs 显式控制、async 分段里都放了 post-await guard，拖动场景的 pause/resume/skipResume 分层清晰。
- **命中测试性能**：pointermove 用 rAF 合并、stickyHit 防连点点穿、ignore + forward 保留悬停检测 —— 都是实战细节。
- **XSS 卫生**：所有用户可控文本（name / 台词）都过 escapeHtml 后才进 innerHTML。
- **纯函数可测性**：screen-zone.js 的 classify/computeSpaces、behaviors.js 的 pickVariant/estimateChainMs 都是无依赖纯函数，天然适合测试。
