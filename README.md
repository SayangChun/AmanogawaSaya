# 天之川沙夜 · 桌面陪伴

以《仰望夜空的星辰》中的 **天之川沙夜** 为形象的 Windows 桌面陪伴应用（**VPet 风格全身桌宠**）。

默认以全身立绘常驻桌面，可拖动、托盘驻留；点击互动、聊天与夸奖，并带有基础的星轨亲密度。

## 运行

```bash
npm install
npm start
```

## 使用

| 操作 | 说明 |
|------|------|
| 拖动角色 | 移动窗口（拖动时进入被拎起姿势） |
| 单击角色 | 展开快捷栏并弹跳回应 |
| 快捷栏 | 聊聊 / 夸奖 / 面板 |
| Esc | 收起面板；在紧凑模式则隐藏到托盘 |
| 托盘图标 | 显示 / 隐藏 / 退出 |

### 全身动态（VPet 帧动画）

沙夜以**姿势帧序列切换**实现动作（类似 VPet 精灵帧动画），脚底为锚点并带轻微 CSS 补间：

- 待机呼吸、左右张望、原地小跑
- 坐下、伸懒腰、挥手打招呼
- 点击弹跳、害羞、庆祝、被拖动拎起
- 固定 **冬制服** 形象；动作由 `assets/animations/<动作>/` 下 PNG 帧驱动

重新打包帧资源：

```bash
python scripts/build_animations.py
```

### 亲密度（基础）

互动会缓慢提升 **星轨亲密度**（0–100），并显示对应称谓。

## 设计说明

1. **全身桌宠**：透明底全身帧，站立在透明窗口桌面上。
2. **帧动画**：`src/character/motion.js` 按 `anim-manifest.js` 的 fps 轮换帧。
3. **立绘来源**：`沙夜原型参考/` 站立制服为基底，各动作关键姿势生成后抠黑底、底对齐。
4. **三档窗口**：紧凑全身 → 快捷栏 → 面板，锚点缩放不乱跳。
5. **纯陪伴**：不含计时、喝水提醒等效率工具。

## 资源

- `assets/animations/`：**动作帧包**（idle / walk / wave / hop / sit / sleep / drag 等）+ `manifest.json`
- `assets/animations/default.png`：默认站立帧
- `assets/portraits/`：历史立绘（备用）
- `assets/faces/`：面部裁切（备用）
- `沙夜原型参考/`：原作向参考图
