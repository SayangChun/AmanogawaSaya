# 天之川沙夜 · 桌面陪伴

以《仰望夜空的星辰》中的 **天之川沙夜** 为形象的 Windows 桌面陪伴应用（**VPet 风格全身桌宠**）。

默认以全身立绘常驻桌面，可拖动、托盘驻留；点击互动、聊天与夸奖，并带有基础的星轨亲密度。

## 运行

```bash
npm install
npm start
```

## 使用

| 操作 | 说明 |
|------|------|
| 拖动角色 | 移动窗口（拖动时进入被拎起姿势） |
| 单击角色 | 对话 / 弹跳回应 |
| 右键角色 | 在脚下展开快捷栏（聊聊 / 夸奖 / 散步 / 小跳 / 坐下 / 漫游 / 星轨 / 隐藏） |
| 快捷栏「星轨」 | 二级菜单：亲密度、星级、互动次数、时段，并可告诉沙夜你的名字 |
| 星轨面板「我的名字」 | 输入你的名字，沙夜会记住；之后聊天偶尔会用名字呼唤你 |
| Esc | 先收起快捷栏或气泡，再隐藏到托盘 |
| 托盘图标 | 显示 / 隐藏 / 退出 |

### 全身动态（VPet 帧动画）

沙夜以**姿势帧序列切换**实现动作（类似 VPet 精灵帧动画），脚底为锚点并带轻微 CSS 补间：

- 待机呼吸、左右张望、原地小跑
- 坐下、蹲下 `crouch`、侧躺 `lie`、趴着 `prone`、伸懒腰、挥手打招呼
- 点击弹跳、害羞、庆祝、被拖动拎起
- 组合动作：沉思 `think`、探头 `peek`、打哈欠 `yawn`、轻笑 `giggle`、问候 `greet`、歇息 `rest`
- 快捷栏「姿势」可主动切换蹲 / 趴 / 躺；角落与屏幕底边 idle 更易进入低位姿态
- **行为多动作**：`src/character/behaviors.js` 里一个行为可配置多条加权变体，每条是动作链（如夸奖 → 害羞→微笑）；链内顺序播放、中间不回 idle
- **屏幕分区姿势**：贴边/角落时更安静张望，开阔区 freer；默认右下角有启动宽限期防过静
- 固定 **冬制服** 形象；动作由 `assets/animations/<动作>/` 下 PNG 帧驱动（部分组合动作复用现有帧）

### VPet 式节奏（不停下来的小动作）

参考 VPet 的「活着」手感做的节奏层优化：

- **高密度小动作**：闲置间隔从 3–8 秒压缩到 1.1–3.7 秒，微动作（摆动/张望/点头/轻笑）占 ~78%，换姿势（坐下/趴）低频出现
- **循环动画轮间变体**：呼吸、摆动这类循环动作每播完一轮，35% 概率倒放 + 速度 ±20% 抖动——同一个呼吸循环每次的节奏都不同，不再匀速往复
- **开播帧率微抖**：每段动作开播时 fps ±12% 随机，叠加 manifest 提速后的基准帧率（idle 3.2fps、talk 3.6fps 等）
- **连招倾向**：即兴链 62% 概率是多步连招（起手→主体→收尾），22% 概率中途插一帧小动作
- **困倦调制**：深夜/活力低时动作间隔与停留自动放缓（×1.5–1.9）——「累了动作变慢」，而不是全天匀速播放

### 连续动画层（Flow · 摆脱帧模板的上限）

帧拼接之上还有一层**程序化连续动画**（rAF 噪声驱动，非关键帧循环）：

- **身体永续微动**：三层不可通约频率的正弦叠加驱动 ±0.9° 摆动、±1.6px 水平漂移、±1px 呼吸起伏——永不精确重复，哪怕同帧停留身体也在流动
- **视线跟随**：光标在窗口内移动时，她会整体微微朝你的方向偏移（±1.8px 平滑趋近）——她在看你
- **拖拽惯性**：被拎着移动时身体朝移动方向倾斜（瞬时速度 → 平滑倾斜，松手回正）
- **帧间 70ms 渐入**：帧切换不再是硬切跳变（单层渐入，无双层叠加粉边）
- **人声打字机**：出字按标点分级停顿——「……」260ms（她的标志性拖沓）、句末 240ms、逗号 150ms、其余每字 ±18ms 抖动

关闭分区姿势（恢复旧 idle）：在渲染进程 DevTools 执行 `localStorage.setItem('saya.zonePoses','0')` 后刷新。

重新打包帧资源：

```bash
python scripts/build_animations.py
# 仅重建蹲/躺/趴等低位姿势帧包：
python scripts/build_rest_poses.py
```

### 亲密度（基础）

互动会缓慢提升 **星轨亲密度**（0–100），并显示对应称谓。

### 记住你的名字

右键沙夜 → **星轨** → 「我的名字」输入框，告诉沙夜你的名字。名字保存在本地（`localStorage`），之后：

- 沙夜会用你的名字回应（`nameSet` 专属台词）。
- 闲聊、点击、夸奖及按时段的问候，偶尔会带上你的名字（个性化后缀）。
- 清空输入框再点「记住」，即可收回名字。

### 对话引擎：全离线，不联网

她靠**本地台词引擎**说话：意图分类（问候 / 安慰 / 夸奖 / 道别 / 自我介绍 / 陈述 / 计划 / 提问）→ 注入记忆 → 台词 + 表情 + 亲密度。纯规则匹配，不发任何网络请求，不需要 API Key，也没有任何调用费用。

### 她的记忆

- **事实卡**：聊天里说「我喜欢…」「我在做…」会被记进「她记得的事」，星轨面板可逐条让她遗忘。
- **约定跟进**：说「周末要去看流星雨」这类带时间的事，她会记下并在到点时主动问你进度。
- **记忆注入**：回复时会用上你的名字、亲密度、时段、事实卡和约定。

### 她会主动开口

每 45 秒一次的优先级队列（互斥 + 冷却防轰炸）：

**到期约定 ＞ 久别重逢（>6h 没说话）＞ 时段切换问候 ＞ 随机想起你说过的事**

### 直播感 · 她像开直播一样在场

在主动性队列之下，还有一层更轻更密的「直播絮叨」（18–42 秒一次，忙碌/聊天时自动安静）：

- **情绪系统**：她有五维心情（开心 / 害羞 / 平静 / 活力 / 想念），被夸害羞冲高、重逢清空想念、深夜活力下降；空闲时情绪向基线回归并持续随机漂移——**没有两次互动她的状态是相同的**
- **动作 = 情绪 × 语境现场合成**：不再有固定动作模板。每次的组权重 = 时段 × 屏幕区域 × 亲密度 × **当前情绪** × 场景偏置，再按「起手? → 主体 → 收尾?」骨架即兴生成，带时长抖动与微插入——同一个「被夸」，心情好时可能蹦一下再红脸，困倦时只是慢慢害羞；害羞值冲高时 shy 动作自然浮现，开心到顶才可能出现庆祝
- **碎碎念**：8 大类随机自言自语（自我感想 / 好奇提问 / 观察你的痕迹 / 星空冷知识 / 想起你说过的事 / 黏人 / 动作预告 / 自娱独处），每类说话也会反过来微调她的情绪
- **她看得见你**：鼠标停在她身上 3 秒会被注意到；短时间被连戳 3 次会有意见；被拎着跑很远会晕；系统空闲 3 分钟她进入自娱模式，回来时她第一个说「你回来了」；锁屏/唤醒、深夜还在（每晚一次夜猫子关怀）都有反应

## 设计说明

1. **全身桌宠**：透明底全身帧，站立在透明窗口桌面上。
2. **帧动画**：`src/character/motion.js` 按 `anim-manifest.js` 的 fps 轮换帧。
3. **立绘来源**：`沙夜原型参考/` 站立制服为基底，各动作关键姿势生成后抠黑底、底对齐。
4. **三档窗口**：紧凑全身 → 快捷栏 → 面板，锚点缩放不乱跳。
5. **纯陪伴**：不含计时、喝水提醒等效率工具。

## 桌面图标

应用图标在 `assets/icons/`：

| 文件 | 用途 |
|------|------|
| `icon.png` / `icon.ico` | 窗口、通知、桌面快捷方式 |
| `tray-32.png` 等 | 系统托盘（Windows 托盘需位图，不能靠 SVG） |

首次可将图标放到桌面：双击运行 **`创建桌面快捷方式.bat`**，会在桌面生成带沙夜头像的「天之川沙夜」快捷方式。

## 资源
